# 🛒 Zepto SQL Data Analysis Project

An end-to-end SQL data analysis project using **PostgreSQL** and **pgAdmin 4** to explore e-commerce inventory, product pricing, discounts, and stock availability.

## 📌 Project Overview

This project analyzes Zepto-style quick-commerce product data to understand inventory patterns, pricing differences, discounts, and product availability using SQL.

## 🛠️ Tools & Technologies

- PostgreSQL
- pgAdmin 4
- SQL
- CSV dataset
- Git and GitHub

## 📊 Analysis Workflow

1. Database and table creation
2. CSV data import
3. Exploratory data analysis (EDA)
4. Data quality and missing-value checks
5. Product pricing and discount analysis
6. Inventory and stock availability analysis
7. Business insights using SQL queries

## 🔍 Key Questions

- How many products are present in the dataset?
- Which categories contain the most products?
- Which products offer the highest discounts?
- How does product availability vary?
- Which products have high MRP but are out of stock?
- How do prices and product weights compare?

## 🚀 How to Run

1. Install PostgreSQL and pgAdmin 4.
2. Create a PostgreSQL database.
3. Open `sql/zepto_analysis.sql` in pgAdmin Query Tool.
4. Run the table creation statements.
5. Import the CSV file into the corresponding table.
6. Run the analysis queries and review the results.

**Note:** Update the CSV path, table name, and column names if they differ in your local setup.
