# 🛒 Zepto SQL Data Analysis Project

An end-to-end SQL data analysis project using **PostgreSQL** and **pgAdmin 4** to explore e-commerce inventory, product pricing, discounts, and stock availability.

## 📌 Project Overview

This project analyzes Zepto-style quick-commerce product data to identify inventory patterns, compare product prices, evaluate discounts, and understand stock availability using SQL queries.

The goal is to extract meaningful business insights from product data and strengthen practical SQL and data analysis skills.

## 🛠️ Tools & Technologies

- **PostgreSQL** – Database management and SQL queries
- **pgAdmin 4** – Database administration and query execution
- **SQL** – Data cleaning, exploration, and analysis
- **CSV** – Dataset storage and import
- **Git & GitHub** – Version control and project hosting

## 📊 Analysis Workflow

1. Database and table creation
2. CSV dataset import into PostgreSQL
3. Exploratory Data Analysis (EDA)
4. Data quality checks and missing-value analysis
5. Product pricing and discount analysis
6. Inventory and stock availability analysis
7. Business insights using SQL queries

## 🔍 Key Business Questions

- How many products are present in the dataset?
- Which product categories contain the most products?
- Which products offer the highest discounts?
- How does product availability vary across categories?
- Which high-MRP products are currently out of stock?
- How do product prices compare with their weights?
- Which products offer the best discounts?
- What inventory patterns can help businesses make better decisions?

## 🚀 How to Run the Project

1. Install PostgreSQL and pgAdmin 4.
2. Create a PostgreSQL database for the project.
3. Open `sql/zepto_analysis.sql` in the pgAdmin Query Tool.
4. Execute the table creation statements.
5. Import `data/zepto.csv` into the corresponding PostgreSQL table.
6. Run the SQL analysis queries.
7. Review the results and document meaningful business insights.

**Note:** Update the CSV file path, database name, table name, and column names according to your local setup and dataset.
